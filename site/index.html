Consultório

Pacientes, fichas de anamnese e termos assinados, num só lugar.

Baixar para Windows Windows 10 ou 11 · cerca de 20 MB · gratuito · versão mais recente

Como instalar (3 passos)

  1. Abra o arquivo baixado

    Clique em Consultorio-Setup.exe na barra de downloads do navegador (ou na pasta Downloads).

  2. Se aparecer a tela azul “O Windows protegeu o computador”

    Clique em Mais informações e depois em Executar assim mesmo.
    Esse aviso aparece com programas novos que ainda não têm um certificado pago. É esperado e não indica problema.

  3. Clique em “Avançar” até terminar

    O programa abre sozinho. No primeiro uso, ele pede o seu nome, e-mail e uma senha. Pronto!

Dúvidas comuns

Onde ficam os dados dos pacientes?

Somente no seu computador. Nada é enviado para a internet. Por isso, use o menu Backup e salve uma cópia num pendrive ou no Google Drive toda semana.

Troquei de computador. Como recupero tudo?

Instale o programa no computador novo e, na primeira tela, use “Já usava o sistema em outro computador?” com o seu arquivo de backup.

Como atualizo?

Quando houver versão nova, o próprio programa mostra um aviso. Baixe por este mesmo botão e instale por cima: os dados continuam guardados.

Quero só experimentar antes

Durante a instalação, marque “Criar também o atalho de DEMONSTRAÇÃO”. Ele abre uma cópia separada com pacientes fictícios (entrar com demo@exemplo.test e senha demonstracao-123).

Desinstalar apaga meus dados?

Não. Os dados ficam guardados mesmo se o programa for removido.
